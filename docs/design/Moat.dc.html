decision · the bad day
Correlation is the whole product on a real incident.
Four alerts in nine minutes that share a process tree are not four problems. They become one incident with a sequence, and the verdict is written about the sequence — a key read alone is ambiguous, a key read followed by an outbound connection and a persistence write is not. This is also the only place the panel is allowed to be alarming.
decision · containment, in order
Under pressure a non-specialist needs a numbered list, not five buttons. Moat proposes the steps in the order that matters, does the machine-side ones itself, and is explicit about the one thing it cannot do for you — rotating a key that has already left the machine.
decision · the bar is the product
The panel gets opened weekly; the waybar glyph is seen every few seconds. So the glyph carries the same three states as the verdict line and nothing else — no count of events, no rule ids, no severity colours competing with your battery.

3g How titles get written so detection 33 doesn't undo all of this
Every detection ships two strings: a title naming the consequence in the user's own terms, and a stake saying what it costs them. Rule ids stay in evidence. Three tests: no jargon a new Arch user wouldn't know, no verb the user didn't do, and it has to make sense with no other context.
detectionwasis
moat-persist-hypr-config-write Hyprland configuration modified by a non-editor Something added itself to your login
moat-cred-ssh-read Private SSH key read by an unexpected program A program you don't recognise read your SSH key
moat-priv-ldso-preload /etc/ld.so.preload created or modified Something is trying to load itself into every program you run
moat-pkg-downloader-exec Package install ran a downloader or decoder An install pulled something extra off the internet
moat-x-noisy-rule Noise guard demoted rule after threshold Moat stopped asking about something that kept happening
the verdict line has four forms
●  Nothing needs you. ●  One thing needs you. / Three things need you. ●  This one needs you now. ●  Watching, with one gap.
No other sentence is allowed in that slot, and it is never a count of events.
words the panel doesn't use
unacked policies tetragon allowlist suppressed demoted ancestry exe tuple
All of them are fine in evidence, in moatctl, and in the TOML. None of them belong in a title.
This is the part that decays without a written rule. A detection is contributed as a rule id and a technical description, and the panel then shows exactly what it was given — which is how the original screens ended up reading like a log. Making the two user-facing strings a required part of a detection, with the tests next to them, is what keeps the third year of Moat sounding like the first.

decision · reversibility before force
Stop it earns its place as the default by being undoable.
A destructive primary is only honest if the worst case is 30 seconds long. Quarantine keeps the file, the kill is recorded with enough state to relaunch, and both are listed for as long as they exist. The same logic covers config writes: if Moat saw the write, it can hold what was there before.
